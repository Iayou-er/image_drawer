# Image Drawer

自动将图片的边缘轮廓通过鼠标拖拽绘制到任意窗口画布上。

支持 **命令行** 和 **图形界面** 两种使用方式，提供 **英文 / 中文** 双语切换，内置可拖拽的**画布可视化编辑器**。

## 安装

```
pip install -r requirements.txt
```

## 图形界面（推荐）

```bash
python ui.py
```

### 界面概览

界面分为左侧控制面板和右侧预览面板。

---

### 左侧 — 控制面板

#### 1. 图片

| 操作 | 作用 |
|---|---|
| **Browse...** | 打开文件选择器，加载一张图片（支持 PNG / JPG / BMP / TIFF / WebP）。加载后自动执行边缘检测并在右侧三个标签页中显示结果。快捷键 `Ctrl+O`。 |
| 路径显示框 | 只读，显示当前已加载图片的完整路径。 |

#### 2. 图片参数

调整这些参数会影响边缘检测和轮廓提取的结果，右侧预览会随之实时更新。

| 参数 | 默认值 | 作用 |
|---|---|---|
| **Canny Low** | 50 | Canny 边缘检测的低阈值。低于此值的像素不被视为边缘。降低此值可以检测到更多弱边缘（但也会引入噪声）。范围 0-255。 |
| **Canny High** | 150 | Canny 边缘检测的高阈值。高于此值的像素直接被认定为边缘。两个阈值配合决定了边缘的丰富程度。如果 Low ≥ High，系统会自动交换两者。 |
| **Blur Kernel** | 5 | 高斯模糊的核大小。在边缘检测前对图像进行模糊处理，去除噪点。值越大模糊越强，边缘越少但越干净。必须为奇数（偶数会自动 +1）。范围 1-31。 |
| **Epsilon** | 0.002 | 轮廓简化系数。值越大，轮廓被简化得越厉害（点数越少，形状越粗糙）；值越小，轮廓越精细（点数越多）。公式：epsilon × 轮廓周长。范围 0.0001-1.0。 |
| **Skip Points** | 2 | 采样间隔。每隔 N 个点取 1 个。设为 1 保留所有点，设为 5 则只保留五分之一。用于进一步减少绘制点数，加快绘制速度。 |
| **Min Area** | 50 | 最小轮廓面积过滤。面积（像素）小于此值的轮廓会被丢弃。用于去除噪声和小碎块。 |
| **Morph Close** | 0 | 形态学闭运算核大小。0 = 禁用。设为 3-7 可将断裂的邻近边缘连接起来。必须为奇数（偶数会自动 +1）。 |
| **Dedup Dist** | 2.0 | 轮廓去重距离阈值（像素）。使用 Chamfer 距离比较两条轮廓的相似度，距离小于此值的视为重复，仅保留面积更大者。0 = 不去重。 |
| **Nearest-neighbor sort** | 关闭 | 开启后，使用贪心最近邻算法重新排列轮廓的绘制顺序。从面积最大的轮廓出发，每次跳到距离最近的未绘制轮廓，减少抬笔空移的总距离。关闭时按面积从大到小排序。 |
| **Target Size** | 关闭 | 限制图片处理的最大尺寸（宽×高）。开启后，图片会被等比缩放并居中放置在黑色画布上。关闭时不限制（但单边 >4096px 会自动缩小到 2048）。范围 1-8192。 |

#### 3. 窗口

| 操作 | 作用 |
|---|---|
| **下拉框** | 列出当前系统中所有可见窗口。选择一个作为鼠标绘制的目标窗口。 |
| **Refresh** | 重新扫描系统中的可见窗口并刷新下拉列表。快捷键 `Ctrl+R`。 |

#### 4. 画布偏移

画布是窗口内实际用于绘制的矩形区域。图片会被等比缩放后居中放置在此区域内。有两种方式定义画布区域：

| 参数 | 默认值 | 作用 |
|---|---|---|
| **Left** | 0 | 画布相对于窗口左上角的水平偏移（像素）。 |
| **Top** | 0 | 画布相对于窗口左上角的垂直偏移（像素）。 |
| **Width** | 0 | 画布宽度（像素）。设为 0 则自动使用窗口宽度。 |
| **Height** | 0 | 画布高度（像素）。设为 0 则自动使用窗口高度。 |
| **Auto-fill** | - | 一键将 Left/Top 归零，Width/Height 填充为当前选中窗口的宽高。 |
| **Select Canvas Region...** | - | 在目标窗口上弹出半透明遮罩层，可拖拽矩形手柄直观选取画布区域。按 `Enter` 确认，`Esc` 取消。 |

> 提示：pygetwindow 返回的窗口坐标包含标题栏和边框。如果画布（客户区）比窗口小，可通过 Left/Top 偏移以及缩小 Width/Height 来补偿。更推荐使用右侧的 **Canvas 标签页** 进行可视化调整。

#### 5. 鼠标设置

| 参数 | 默认值 | 作用 |
|---|---|---|
| **Speed** | 0.002 秒/点 | 鼠标每移动一个插值点后暂停的秒数。值越小绘制越快，但游戏可能丢帧；值越大绘制越慢，但更稳定。设为 0 则全速移动。 |
| **Contour Pause** | 0.1 秒 | 每笔之间（抬笔后）的暂停秒数。给目标程序处理 mouse up 事件的时间。 |
| **Interp. Step** | 5 像素 | 插值步长。两点之间距离超过此值时，会线性插入中间点以保证鼠标移动平滑。值越小路径越平滑但点数越多。 |
| **Start Delay** | 3.0 秒 | 倒计时秒数。点击 Start Drawing 后给出准备时间，期间可将鼠标移到目标窗口上方。 |
| **Pause between strokes** | 开启 | 是否在每笔之间暂停（暂停时长为 Contour Pause）。关闭则连续绘制，笔画间无停顿。 |
| **Button** | left | 绘制使用的鼠标按键。可选 left / right / middle / x1 / x2。 |
| **Manual mode** | 关闭 | 手动控制模式。程序将鼠标移动到每条笔画的起点后暂停，由用户**按住**所选按键来控制绘制节奏，松开则暂停。适合需要与目标窗口交互的场景。 |

#### 6. 操作按钮

| 按钮 | 作用 |
|---|---|
| **Dry Run** | 不实际操作鼠标，仅计算并展示本次绘制的统计信息：轮廓数、总点数、预计耗时、画布位置、排序方式和去重情况。用于在实际绘制前预估效果和时间。 |
| **Start Drawing** | 开始绘制。先进行倒计时（见 Start Delay），然后控制鼠标逐笔在目标窗口内描画轮廓。期间进度条和耗时实时更新。 |
| **Abort** | 立即中止绘制。鼠标会立刻释放，已绘制的笔画保留。也可按 `Esc` 键触发。 |

绘制过程中，左侧除 Abort 以外的所有控件都会被禁用，防止误操作。

---

### 右侧 — 预览面板

| 标签页 | 显示内容 |
|---|---|
| **Original** | 加载的原始图片（经过缩放和黑边补白处理后的版本，与处理管线的输入完全一致）。 |
| **Edges** | Canny 边缘检测的输出结果。白色线条 = 检测到的边缘。可据此调整 Canny Low/High 和 Morph Close。 |
| **Overlay** | 绿色轮廓线叠加在原图上。显示最终会被鼠标绘制的笔画形状。可据此调整 Epsilon、Skip Points、Min Area 等参数。 |
| **Canvas** | 目标窗口截图 + 可拖拽的矩形选区。用鼠标拖拽手柄或移动选区来**可视化定义画布区域**，左侧的 Left/Top/Width/Height 数值会实时同步。快捷键 `W`=全选窗口，`F`=贴左上角。 |

预览面板下方有一个 **信息面板**，显示当前图片的处理统计数据（轮廓数、点数、尺寸、去重情况）。Dry Run 或绘制完成后会更新为详细报告。

## 命令行

```bash
# 预览边缘效果（不实际绘制）
python main.py cat.png --preview

# 查看统计信息
python main.py cat.png --dry-run

# 列出所有可见窗口
python main.py --list-windows

# 实际绘制
python main.py cat.png

# 指定窗口 + 画布偏移 + 右键绘制
python main.py cat.png --window-title "My Game" --canvas-offset "10,10,780,580" --start-delay 5 --button right

# 手动模式（用户自行控制按键）
python main.py cat.png --manual
```

## 打包为独立 EXE

```bash
# 双击运行构建脚本
build.bat

# 或手动构建
pip install pyinstaller
python -m PyInstaller --clean build.spec
```

输出 `dist/ImageDrawer.exe`，无需安装 Python 即可运行。

## 流程

```
图片 → 灰度化 → Canny 边缘检测 → 轮廓提取 → 简化排序 → 鼠标拖拽绘制
```

## 常用参数（CLI）

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--preview` | - | 预览处理结果，不绘制 |
| `--dry-run` | - | 显示统计信息，不绘制 |
| `--list-windows` | - | 列出所有可见窗口 |
| `--window-title` | Godot | 目标窗口标题关键词（不区分大小写） |
| `--canvas-offset` | 0,0,0,0 | 画布在窗口内的区域 `left,top,w,h` |
| `--start-delay` | 3.0 | 开始前倒计时秒数 |
| `--speed` | 0.002 | 鼠标移动速度（秒/插值点） |
| `--button` | left | 鼠标按键：left / right / middle / x1 / x2 |
| `--manual` | - | 手动模式：由用户按住按键控制绘制节奏 |
| `--canny-low` | 50 | Canny 边缘检测低阈值 |
| `--canny-high` | 150 | Canny 边缘检测高阈值 |
| `--morph-close` | 0 | 形态学闭运算核大小，连接断裂边缘 |
| `--nearest-neighbor` | - | 最近邻路径排序，减少空移 |
| `--no-pause` | - | 笔画间不暂停 |
| `--interpolate-step` | 5 | 鼠标插值步长（像素） |
| `--skip-points` | 2 | 每隔 N 个轮廓点取 1 个 |
| `--min-area` | 50 | 最小轮廓面积过滤 |

## 热键

| 按键 | 场景 | 作用 |
|---|---|---|
| `Ctrl+P` | 任意 | 全屏截图 |
| `Esc` | 绘制中 | 立即停止绘制 |
| `Enter` | 遮罩选画布 / 截图 | 确认选区 |
| `Esc` | 遮罩选画布 / 截图 | 取消选区 |
| `W` | 遮罩 / 编辑器 / 截图 | 选区设为全尺寸 |
| `F` | 遮罩 / 编辑器 | 选区贴到窗口左上角 |

## 模块

| 文件 | 职责 |
|---|---|
| `main.py` | CLI 入口，参数解析，模块编排，坐标转换 |
| `ui.py` | PySide6 图形界面，所有参数控件，预览，信号/槽 |
| `ui_thread_worker.py` | QThread 工作线程，后台运行鼠标绘制 |
| `i18n.py` | 中英双语翻译字典 |
| `image_processor.py` | 边缘检测，轮廓提取，路径简化，去重排序 |
| `window_finder.py` | 窗口定位，激活，画布区域，坐标映射，窗口截图 |
| `mouse_controller.py` | 鼠标拖拽画线，线性插值，热键中断，手动模式 |
| `canvas_selector.py` | 画布区域可视化编辑器（遮罩层 + 内嵌控件） |
| `build.spec` | PyInstaller 打包配置 |
| `build.bat` | 一键打包脚本 |
